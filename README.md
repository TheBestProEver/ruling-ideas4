# Ruling Ideas

A 20-minute classroom game on Marx's *Theses on Feuerbach* and the *Communist Manifesto*, with references to *The German Ideology*, "Estranged Labour," Adam Smith and Ibn Khaldun.

This repo is the trivia presenter. Put it on a projector, and the Host clicks through the questions while the Banker hands out paper currency notes.

## Put it online with GitHub Pages

1. Create a new public repository on GitHub, for example `ruling-ideas`.
2. Upload `index.html`, `data.js`, `Ruling_Ideas_Game_Kit.pdf` and `Ruling_Ideas_Currency.pdf` to the root of the repo (Add file → Upload files).
3. Go to **Settings → Pages**. Under "Build and deployment," set Source to **Deploy from a branch**, pick `main` and `/ (root)`, and save.
4. After a minute or two, the site is live at `https://YOUR-USERNAME.github.io/ruling-ideas/`.

You can also just open `index.html` in a browser. It works offline.

## Controls

- **Right arrow / Space:** next slide. **Left arrow:** back.
- **A:** show or hide the answer (or the hint, on discussion slides).
- **T:** start the timer (20 s for trivia, 30 s for hard questions and Round 4 prompts). The last 3 seconds take over the screen as "3, 2, 1."
- **M:** menu to jump to any round or the debrief. Rounds 1 to 3 each end with a discussion slide.
- On the "Who rules?" slide, click the winning team. The header then shows the Ruling Class, and the rule it picks in Round 2.

## Print kit

`Ruling_Ideas_Game_Kit.pdf` has the full rules, Host and Historian sheets, discussion questions, the Ruling Class placard, identity cards and game cards.

`Ruling_Ideas_Currency.pdf` has 60 numbered Bank of Han Xue notes (10 per page), the same for every team. Each says one million but counts as 1 token. Print it in color and cut along the dashed lines.
